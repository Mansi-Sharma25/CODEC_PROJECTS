# 💻 CODEC Python-Developer Internship Projects

Welcome to my **Python-Developer internship projects** repository!

This repository contains the projects I developed as part of my Python Developer Internship.
The repository includes two projects- Automated Resume Parser and Real-Time Stock Market Dashboard. Each project focused on Python programming, data processing, API integration, visualization, and application development.

## 📌 Projects Included

### 1. 📄 Automated Resume Parser

An automated resume parsing application that extracts useful information from PDF resumes and organizes the extracted information for easier viewing and storage.

**Key Features:**
- Upload resume in PDF format
- Extract text from PDF resumes
- Extract candidate information such as email, phone number, skills, education
- Store parsed resume information in a SQLite database
- Display extracted information through the application

**Technologies Used:**
- Python
- PDFPlumber
- Regular Expressions (Regex)
- SQLite

**Outcome:**

The project demonstrates how Python can be used to automate resume data extraction and organize candidate information in a structured database.

---

### 2. 📈 Real-Time Stock Market Dashboard

An interactive stock market dashboard that fetches stock market data and visualizes it through an easy-to-use Streamlit interface.

**Key Features:**
- Select stocks and different time periods from the dashboard
- Fetch stock market data using an API
- Display current stock price
- Display day high and day low and trading volume
- Calculate price change percentage
- Visualize closing prices using an interactive Plotly chart

**Technologies Used:**
- Python
- Requests
- Pandas
- Plotly
- Streamlit
- Yahoo Finance API

**Outcome:**

The project demonstrates real-time API data retrieval, data processing, financial data visualization, and interactive dashboard development using Python.
